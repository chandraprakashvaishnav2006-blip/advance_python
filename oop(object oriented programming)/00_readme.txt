oop(object oriented programming)
it is a programming paradigm where class and object are created to solve the real life problems 
 

 features of oop:
 1. increase code reusability 
 2. encapsulation: it combines data and methods into single unit .
 3. polymorphism : polymorphism means one method have diffrent behaviour.
 4. inheritance: it allows to reuse the functions and properties of existing class
 5. abstraction : it is used to show only necessary things and hide other things 
 6. data security
 7. modularity: a large program is divided into class and functions
